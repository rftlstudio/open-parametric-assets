# Open Parametric Assets v0.4.0 articulation measurements

On 2026-11-27, MuJoCo 3.3.7 ran the default linter on the published release's 217 MJCF records. The models were generated from commit `3992be5ff4fba276d0ec993727f5858b6ed7387a`. The clean run produced zero error findings. The linter detected 803 of 803 applicable injected faults across seven classes. [Release dataset](https://huggingface.co/datasets/rftlstudio/open-parametric-assets/tree/v0.4.0) · [Generator revision](https://github.com/rftlstudio/open-parametric-assets/commit/3992be5ff4fba276d0ec993727f5858b6ed7387a)

The clean warnings were 39 small moving bodies below 1 g (A003) and 114 grasp points over 5 mm from their link's collision surface (A005). Small button caps and recessed grips account for these measurements. Another 40 low-inertia joints with zero armature triggered informational findings (A008). Thresholds, severity and the fixed probe trajectories are documented in the [rule reference](../docs/LINT.md).

## Reproduce

From this PR's checkout, with the v0.4.0 manifest and its MJCF tree under `dist/release`, run:

```sh
python -m pip install -r sim/requirements.txt
python -m sim.lint.faults --dataset dist/release --out dist/lint-release
```

The separate 29-record CI sample includes parameter corners. It detected 104 of 104 applicable faults. Inspect the [CI table](faults/matrix.md) or the [per-record targets and fired rule IDs](faults/matrix.json).
